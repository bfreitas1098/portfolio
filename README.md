## Projects Featured

### Fitness Planner
A full-stack fitness tracking and workout planning application built with React, Node.js, Express, Prisma, and PostgreSQL. Users can create workouts, manage exercises and sets, and track training progress through a structured interface.

### AI Lung Disease Detector
A machine learning-powered web application designed to analyze chest X-ray images and predict potential lung disease indicators. The application integrates a trained deep learning model with a responsive React frontend to create an accessible and user-friendly diagnostic experience.

### ArtristryByMel
A responsive business website built to present the professional work and artwork by talented artist Melvin Lozado. The site focuses on accessibility, structured layouts, and clean UI design to support client engagement.
